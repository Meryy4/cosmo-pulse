# Workflow

- `main` always runs end to end. Never push broken code to `main`.
- One branch per feature: `feat/voice-features`, `feat/baseline`, `feat/llm-rag`...
- Small pull requests, reviewed by the other teammate.
- Commit messages: `feat:`, `fix:`, `docs:`, `test:`.

## Ownership
| Module | Owner |
|---|---|
| physio, baseline, detection, crew, api | Oussama |
| voice, llm, knowledge_base | Meryeme |
| dashboard, docs, demo video | Both |
